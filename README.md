# BENEF CITY — images publiques

Ce dépôt ne contient **que des images destinées à être publiques** : les bannières affichées dans la liste des serveurs FiveM et le logo.

Le code du serveur vit dans un dépôt privé séparé.

| Fichier | Usage | Format imposé |
|---|---|---|
| `banner-detail.jpg` | Panneau de détails du serveur dans FiveM | 1900 × 400 |
| `banner-connecting.jpg` | Écran de connexion | 1920 × 1080 |
| `logo.jpg` | Logo carré (Discord, réseaux) | 320 × 320 |

Les URL directes sont de la forme :

```
https://raw.githubusercontent.com/wewcmoi31/benef-city-assets/main/banner-detail.jpg
```

> ⚠️ Ces adresses sont référencées dans `server.cfg`. Renommer un fichier casse l'affichage dans FiveM.
